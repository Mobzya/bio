# Mobzya / Личное пространство

**Математика, код и человек за моделью.**

Мини-сайт о Mobzya: ML engineering, AI engineering и data science. Строгий чёрный минимализм, интерактивная 3D-структура и адаптивная вёрстка.

## На сайте

- Плавная сборка страницы из белого экрана: терминал, постепенно печатающийся текст и разные траектории появления. Порядок разделов и положение прокрутки сохраняются.
- Статистика GitHub, языки и инструменты из публичных проектов. При недоступности API используется сохранённый снимок, без выдуманных чисел.
- Math, Computer Science и ML с живыми визуализациями.
- Цветная фотолента в случайном порядке, с постоянной скоростью и переключателем Ч/Б. В анимации появляется целиком.
- Контакт: [Telegram @Mobzi_t](https://t.me/Mobzi_t).

При системной настройке уменьшения движения вступительная анимация и автопрокрутка отключаются.

## Локальный запуск

```sh
npm ci
npm run dev:local
```

Сайт доступен на **http://localhost:5173**. Версия Node.js указана в `.node-version`.

```sh
npm test          # тесты
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Публикация на Cloudflare Pages

Подключите GitHub-репозиторий `Mobzya/bio` в Cloudflare Pages и задайте:

| Настройка | Значение |
| --- | --- |
| Ветка | `main` |
| Команда сборки | `npm run build` |
| Каталог результата | `dist` |
| Корневая папка | Оставить пустой |

После первой успешной сборки Pages выдаст HTTPS-ссылку `https://<имя-проекта>.pages.dev`. Её можно добавить в профиль Telegram. При подключённой Git-интеграции новые коммиты в `main` запускают обновление сайта. [Инструкция Cloudflare](https://developers.cloudflare.com/pages/framework-guides/deploy-a-react-site/).

## Персонализация

Биография, контакты, Kaggle и интересы: [`src/data.ts`](src/data.ts). Фотографии: `public/photos/`. Сценарий сборки: [`src/lib/build-intro.ts`](src/lib/build-intro.ts).

Снимок статистики обновляется командой `npm run sync:github`. GitHub-токены и секреты Telegram-бота в клиентском коде не нужны.

**Стек:** React · TypeScript · Vite · Three.js · Lucide. Локальные шрифты Manrope и IBM Plex Mono используются по SIL Open Font License; лицензии находятся в `public/fonts/`.
