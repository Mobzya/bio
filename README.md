# Mobzya / Personal Space

Монохромный сайт-портфолио на React, TypeScript, Vite и Three.js.

## Запуск

```sh
npm install
npm run dev:local
```

Откройте http://localhost:5173. Для телефона в той же Wi-Fi сети доступен адрес, который сервер показывает после `Network`.

`dev:local` передаёт HTTP-ответы небольшими порциями: в текущем локальном окружении крупные ответы зависают. Обычный запуск в других окружениях: `npm run dev`.

```sh
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Публикуйте содержимое этой папки на статическом хостинге в корне домена.

## Render

Конфигурация `render.yaml` создаёт отдельный Static Site `mobzya-bio`, не затрагивая сервис Telegram-бота. Статический хостинг бесплатный в пределах лимитов трафика и минут сборки вашего аккаунта Render.

[Развернуть на Render](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FMobzya%2Fbio)

Репозиторий исходников приватный. Перед развёртыванием дайте GitHub-приложению Render доступ к `Mobzya/bio`, если он ещё не предоставлен. Затем создайте Blueprint из этого репозитория и подтвердите создание Static Site. Render выдаст публичный HTTPS-адрес после успешной сборки. Новые коммиты в `main` автоматически обновляют сайт.

При ручном создании через `New > Static Site` используйте:

- Repository: `Mobzya/bio`
- Branch: `main`
- Build Command: `npm ci --include=dev && npm run build`
- Publish Directory: `dist`

Версия Node.js закреплена в `.node-version`. Команда запуска сервера, токен GitHub и секреты Telegram-бота для публикации сайта не нужны.

## Содержание

Имя, GitHub, Telegram, ссылка Kaggle, описание и интересы задаются в `src/data.ts`. Тексты интересов и биографии являются предложенным черновиком. Для связи указан Telegram `Mobzi_t`.

Ссылка Kaggle задаётся в `profile.kaggleUrl`; её ввод на сайте сохраняется локально. Статистика Kaggle не выдумывается: показывается ссылка на указанный профиль.

В галерее 68 оригинальных фотографий из предоставленного архива. Порядок случайный при каждой загрузке, начальный режим цветной, переключатель включает чёрно-белый фильтр. Лента движется автоматически с постоянной скоростью 18 пикселей в секунду, без ручной прокрутки или ускорения. Полноэкранный просмотр сохраняет весь снимок. Файлы лежат в `public/photos/`, список и пропорции задаются в `src/data.ts`.

При каждом открытии страницы проходит примерно 47-секундная пошаговая сборка: белый экран, команды терминала, появление и выравнивание настоящих элементов, переход к чёрной палитре двумя дискретными шагами. Выполненная команда открывает не более двух фрагментов; фотографии появляются парами в том же случайном порядке, что и в ленте. Лента начинает двигаться после появления первой пары. Сценарий задаётся в `src/lib/build-intro.ts`, длительность учитывает число фотографий. Поздно пришедшие строки GitHub подхватывают текущий этап сборки. Прокрутка остаётся свободной, завершение не меняет её положение. Карточки интересов оживают при наведении, клавиатурном фокусе или нажатии на телефоне. При системном предпочтении уменьшенной анимации сборка пропускается, движение отключается.

Шаг времени ограничен 80 мс: задержки кадров и возврат из фоновой вкладки не пропускают команды и не объединяют порции контента. На медленном устройстве сборка может длиться дольше.

## GitHub

Данные загружаются через публичный [GitHub REST API](https://docs.github.com/en/rest/repos/repos), без токенов в клиентском коде. Поддерживается пагинация. Звёзды и языки суммируются по собственным публичным репозиториям, языки сравниваются по байтам кода. Инструменты определяются по `package.json`, `requirements*.txt` и темам репозиториев; рейтинг означает число проектов с найденным инструментом, а не уровень владения.

Для защиты от лимитов используется часовой кеш браузера. При ошибке API остаётся реальный сохранённый снимок с датой, без фиктивных чисел. Неполный анализ явно отмечается. Снимок обновляется перед публикацией:

```sh
npm run sync:github
npm run build
```

Для `sync:github` нужен Node.js 22.18+ или 24+, поддерживающий запуск TypeScript.

Локальные Manrope и IBM Plex Mono распространяются по SIL Open Font License; лицензии включены в `public/fonts/`.
